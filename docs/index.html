Sankhya Repo Updater

Mantém os módulos Sankhya atualizados todos os dias, sozinho — tanto os do GitLab quanto os que migraram para o GitHub. É um arquivo só, você configura tudo numa janela e não edita nada.

Baixar Sankhya-Repo-Updater.zip · Windows · 1 arquivo Instala em ~2 minutos.
Já usa a versão antiga? Veja aqui.

Antes de começar

  • Git instalado (o mesmo que você já usa para clonar os projetos).
  • Sua conta do GitHub com acesso à organização sankhya-tech — os módulos de lá são privados.
  • VPN FortiClient configurada, para os módulos do GitLab. Para ela conectar sozinha, deixe o FortiClient fixado na barra de tarefas (botão direito no ícone → Fixar na barra de tarefas).

Não precisa ter os projetos clonados: o que faltar, ele clona sozinho.

Instalação

1

Baixe e extraia numa pasta fixa

Baixe o .zip, clique nele com o botão direito → Extrair tudo... → e use esta pasta como destino:

C:\SK-Code\Sankhya-Repo-Updater
Importante: não abra o arquivo de dentro do .zip e não mova a pasta depois. A atualização diária fica apontando para o lugar onde o arquivo estava quando você instalou. (Se precisar mover, é só abrir de novo e clicar em Salvar e instalar.)
2

Dê 2 cliques em Sankhya-Repo-Updater.bat

Abre a janela de configuração, que já procura sozinha os módulos na pasta C:\SK-Code.

O Windows pode perguntar se confia no arquivo, porque ele veio da internet:
• “Aviso de segurança — O fornecedor não pôde ser verificado” → clique em Executar.
• Tela azul “O Windows protegeu o computador” → Mais informações → Executar assim mesmo.
Isso só aparece na primeira vez.
3

4

Clique em Salvar e instalar

Ele grava a configuração, cria a atualização diária e o atalho Atualizar modulos Sankhya na área de trabalho. Em seguida pergunta se você quer atualizar agora — responda Sim.

Na primeira vez, o navegador abre pedindo para entrar no GitHub. Faça o login com sua conta da Sankhya e autorize. Isso fica salvo, não pede de novo.

Pronto quando: o rodapé da janela mostra “Instalado: verificação diária às 11:00.” e aparece a mensagem Resultado da atualização com o que foi feito.

No dia a dia

  • Todo dia às 11h ele atualiza tudo escondido, sem abrir janela. Se o computador estiver desligado nesse horário, roda assim que você ligar.
  • Só aparece um aviso no canto da tela quando algum módulo foi atualizado ou deu erro.
  • Quer atualizar na hora? Use o atalho Atualizar modulos Sankhya na área de trabalho.
  • Seu trabalho não commitado nunca é perdido: se houver algo para baixar, ele guarda suas alterações no stash antes (recupere com git stash pop).

Quer mudar algo? (incluir ou tirar módulo, horário, VPN) — abra o Sankhya-Repo-Updater.bat de novo, ajuste e clique em Salvar e instalar.

Já usava a versão antiga?

Aquela do Instalar-Automatico.bat. Basta seguir os 4 passos acima: ao clicar em Salvar e instalar, a atualização diária antiga é substituída pela nova. Se o rodapé mostrar “Há uma verificação diária de OUTRA versão instalada”, é exatamente isso — clique em Salvar e instalar.

Depois disso, a pasta da versão antiga pode ser apagada.

Deu algum problema?

Apareceu “sem acesso a https://github.com/...”

Falta o login no GitHub ou sua conta não tem acesso à organização sankhya-tech. Rode o atalho Atualizar modulos Sankhya uma vez e faça o login quando o navegador abrir. Se continuar, peça acesso à organização.

A atualização automática das 11h nunca abre login — por isso o primeiro login tem que ser pelo atalho ou pelo botão Atualizar agora.

Os módulos do GitLab não atualizaram (VPN)

Os módulos do GitLab precisam da VPN. Quando ela está caída, só eles ficam de fora naquele dia — os do GitHub atualizam normalmente.

Para a VPN conectar sozinha: deixe marcado Conectar a VPN automaticamente, o FortiClient fixado na barra de tarefas e o login do Google (SSO) já feito pelo menos uma vez. Se faltar algo, ele só abre o FortiClient e avisa.

“git pull --ff-only falhou (provável divergência)”

Você tem commits locais nesse branch que não estão no servidor. Ele não faz merge sozinho para não bagunçar seu trabalho — resolva nesse repositório com git pull ou git rebase.

“Filename too long”

Habilite caminhos longos no Windows: abra o PowerShell como Administrador e rode:

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\FileSystem" -Name LongPathsEnabled -Value 1 -PropertyType DWord -Force

Um módulo meu não apareceu na lista

Se ele está fora de C:\SK-Code, clique em Procurar no computador todo (leva 1–2 minutos). Se ainda não está clonado e não aparece, use Adicionar módulo por URL... e cole o endereço do repositório.

Onde vejo o que aconteceu?

Botão Logs na janela. Os arquivos ficam em %LOCALAPPDATA%\SankhyaRepoUpdater\logs, um por mês.

Desinstalar

Abra o Sankhya-Repo-Updater.bat e clique em Desinstalar. Remove a atualização diária e o atalho. Seus projetos não são tocados. Depois pode apagar a pasta do arquivo.
